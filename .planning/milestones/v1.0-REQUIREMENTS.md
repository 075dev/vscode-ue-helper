### Phase 1: 面板框架 + 操作按钮 ✅

- [x] **CTRL-03**: 面板标题栏显示当前项目名称和引擎版本

- [x] **CTRL-06**: 面板包含 Create Project / Generate compile_commands 项目管理按钮

- [x] **CTRL-10**: 面板按钮操作结果通过通知或面板内消息反馈给用户
