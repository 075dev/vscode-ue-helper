## 推荐拆分方案(Phase 5 第一 wave 候选)

按 god size 降序:`bridge.ts(795) → controlPanel.html.ts(645) → workspace.ts(489) → config.ts(306)`。

每个文件拆 2 子模块,facade pattern 保留原 class export:

### Phase 5 wave a: `src/clangd/proxy/bridge.ts` (Wave 6 优先)

```
src/clangd/proxy/bridge/
├── index.ts            # public API re-export(原 facade)
├── lsp.ts              # LSP 协议层(handleIncomingRequest / sendResponse / framing)
└── transform.ts        # payload 转换(UE 宏适配 / hover 内容增强)

子依赖: proxy/processBridge.ts(已存在)、proxy/framing.ts(已存在)
公共 API 保留:
  - 类型:LspBridge(export type)
  - 函数:createLspBridge / transformLspPayload
单 commit 一个文件拆完。Wave 6 内 1 commit。
```

### Phase 5 wave b: `src/ui/controlPanel.html.ts`

```
src/ui/controlPanel/
├── index.ts                # facade
├── sections.ts             # 分区 HTML 模板(各 panel group)
└── actions.ts              # 交互逻辑(createWebview / messageChannel)

公共 API 保留: 同名 default export。
```

### Phase 5 wave c: `src/core/workspace.ts`

```
src/core/workspace/
├── index.ts               # facade + WorkspaceState class 保持原位置
├── constants.ts           # 常量 + type alias(WorkspaceField / 等)
└── api.ts                 # 派生 getter methods(projectDir/engineRoot/...)

公共 API 保留: 
  - export class WorkspaceState implements vscode.Disposable
  - export type { WorkspaceFolderInfo / WorkspaceField }
  - 全部 36 callers 的 import path 保留(`from '@core/workspace'`)
```

### Phase 5 wave d: `src/core/config.ts`

```
src/core/config/
├── index.ts               # Config class facade + 类型
├── defaults.ts            # 默认值表(DEFAULT_*)
└── validation.ts          # 校验函数(inspect/validate/keyBounds)

公共 API 保留: Config class + 类型,@core/config 路径不动。
```

## 拆分的"门禁绿"验证(每 wave 一致)

每波 commit 后必跑:

```bash
npm run typecheck && npm run lint && npm run test:unit && npm run build
```

预期:0 error / 0 break。`test/unit/core/ssot.test.ts` 必须仍 pass,`test/unit/core/workspace.test.ts` 必仍 pass(任何 import 漏改 → 这 2 个 test 文件必炸)。

## 风险与回滚

- **风险**:公共 API 重排导致 consumers 编译失败;Phase 9 SSoT 收尾已大量 import `@core/workspace` / `@core/config` 作为稳定路径。
- **回滚**:每个 wave 是独立 commit,git revert 即可回滚单个 wave。
- **跨 wave 锁**:4 个文件互不引用拆分,无锁冲突,可顺序 commit。
