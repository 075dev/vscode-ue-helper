<objective>
Deliver Phase 8 of v1.2 (un-park, scoped to UE reflection header auto-sync): a single new `HeaderWatcher` module that subscribes to `vscode.workspace.onDidSaveTextDocument`, debounces 1500 ms across saves of UE reflection headers (`.h` files containing UCLASS/USTRUCT/UENUM/UINTERFACE/UFUNCTION/UPROPERTY/GENERATED_BODY/UMETA within the project's source tree), and triggers the existing `generateCompileCommands()` pipeline so UBT regenerates `.generated.h` files in step with the user's `.h` line layout. Adds the new `vscodeUEHelper.clangdHeaderWatcher.enabled` setting (default true), 3 status-bar i18n keys, and a cancellation hook invoked by the manual `vscodeUEHelper.generateCompileCommands` command so manual and auto-trigger cannot run UBT twice in quick succession.

Purpose: Prevents clangd's `FID_*_<line>_PROLOG unknown_typename` errors when the user edits reflection headers (any non-GENERATED_BODY line change shifts the macro line number UHT hard-codes into FID names). This is the "macro passthrough" prerequisite for the rest of Phase 8 (CLANGD-02), without which downstream completion / goto / reference features cannot work reliably.

Output: One production module `src/clangd/headerWatcher.ts`, 1 line of activation wiring in `src/extension.ts`, ~3 lines cancellation wiring in `src/commands/generateCompileCommands.ts`, 1 setting entry in `package.json`, 1 strongly-typed getter in `src/core/config.ts`, 3 i18n keys in `en.json` / `zh.json`.
