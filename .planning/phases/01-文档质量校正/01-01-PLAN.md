## Notes for Executors

1. **使用 patch 工具,不用 sed/awk**:patch 的模糊匹配策略可兜底微小的全角/半角空格偏差,避免误改。建议每次只改 1 处,先验证再继续下一处,以便出错时定位。

2. **锚点句必须包含前缀 emoji / 数字**:为防误匹配其他位置的相同字符串,锚点统一从 `**...**` 粗体短句后的标点 + 完整句末符号开始,例如 `**只跑 unit**:\`npm run test:unit\`。`

3. **不要扩展到行 113 / 114**: #12 (行 113) 已用 ✅ + 删除线, #13 (行 114) 是另一议题,本计划不动。

4. **执行顺序**:建议从行 102 (D-01) 开始,逐行向下锚定,避免 4 处同时修改导致 patch 匹配错乱。

5. **无 commit / push 要求**:本计划只要求文件修改正确;commit 留 Phase 1 收尾统一做。

6. **任务时间**:单文件 4 处纯文本追加,执行应 < 5 分钟。建议单 task 不拆分,避免 4 个独立 patch 互相干扰。
