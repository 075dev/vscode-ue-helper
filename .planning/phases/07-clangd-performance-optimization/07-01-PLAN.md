为 Phase 7 (clangd 性能优化) 落地「内容哈希指纹 + 增量缓存层 + 状态栏三段可视化」三层能力：
- **第一层** fingerprint 模块基于 `.uproject` + `*.Build.cs` + `Target.cs` 的 SHA256 拼接（per D-09），将 UBT 重复触发（5-30s）压缩为指纹命中后的 < 200ms 读取；
- **第二层** CompileCommandsCache + HeaderCache 提供本地增量缓存（per D-08/D-13/D-14），命中即跳过 UBT 子进程；
- **第三层** PerfStatusBar 三段性能面板（per D-04/D-05），把生成耗时 / preparse 命中率 / 增量扫描延迟在状态栏实时呈现，让用户对三个 SUCCESS CRITERIA（< 5s / > 80% / < 200ms）有可视化反馈。
