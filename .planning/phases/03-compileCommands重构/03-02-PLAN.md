# Plan 03.02: cache 子模块提取

<threat_model>
**ASVS Level 1 check** — 本计划只移动既有缓存编排，不创建新攻击面。
- [ ] 无新增输入校验缺口（`projectDir`、fingerprint 与 cache entry 输入语义不变）
- [ ] 无新增认证/授权路径（compileCommands 仅访问本地工作区）
- [ ] 无新增密钥处理（缓存仅保存路径、指纹与统计，不含凭据）
- [x] 路径穿越：`compileCommandsCache.ts` 的既有路径派生/约束逻辑原样复用；提取层不得绕过该 cache class 或扩大 `projectDir` 输入面
- [x] 缓存完整性：`CompileCommandsCache` 的临时文件加 rename 原子写入保持不变（Security 防御 3）
- [x] 大小 DoS：5MB 缓存上限由既有 cache class 保持（Security 防御 2）
- [x] 文件系统竞态：本计划不触碰 symlink/copy 行为
- **风险级别：** low（无算法变化，ASVS L1 足够）
- **阻断条件：** 任一提取路径绕过 cache class 的 5MB/原子写入防御，或出现 high severity threat
</threat_model>

<objective>
把 fingerprint/cache 快路径与缓存写入编排提取到约 80 行的 `cache.ts`，让主入口保留性能埋点和高层 UBT 流程，同时保持快路径、fallback 与错误降级语义不变。
</objective>
