# Plan 03.03: symlink 子模块提取

<threat_model>
**ASVS Level 1 check** — 本计划是文件系统逻辑的 1:1 提取，不扩大可写路径或输入来源。
- [ ] 无新增输入校验缺口（`jsonPath`、`projectPath` 与可选 WorkspaceState 语义不变）
- [ ] 无新增认证/授权路径（compileCommands 仅操作本地工作区文件）
- [ ] 无新增密钥处理（仅处理路径，不处理凭据）
- [x] 路径穿越：`workspace.projectDir` / `clangdHelperDir` 优先路径与既有 fallback 计算保持不变；不得新增调用方可控目标目录
- [x] 缓存完整性：本计划不改 `CompileCommandsCache` 原子写入（Security 防御 3）
- [x] 大小 DoS：5MB cache 上限不受影响（Security 防御 2）
- [x] 文件系统竞态：先清理既有 file/symlink，再尝试 symlink；失败后独立尝试 copy，copy 失败抛出包含 source/target 的明确错误，保持旧行为
- **风险级别：** low（既有本地 fs 流程平移，ASVS L1 足够）
- **阻断条件：** copy 失败被吞掉、目标路径范围扩大、错误中新增敏感内容，或发现 high severity threat
</threat_model>
