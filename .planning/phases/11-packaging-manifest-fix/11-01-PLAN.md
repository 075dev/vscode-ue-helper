# Phase 11 — 打包与清单修复 (Plan 01)

## Goal

Fix 3 `vsce package` warnings (missing LICENSE / missing repository / bundling bloat from `*.map` files) and
add a pre-build clean step so stale `out/src/` and `out/test/` stop shipping in the `.vsix`. Prune
non-existent tool-dir rules from `.vscodeignore` per STR-02.

## Requirement Traceability

| REQ    | What                                                              | Where delivered                              |
|--------|-------------------------------------------------------------------|----------------------------------------------|
| PKG-01 | MIT LICENSE file at repo root with copyright line                 | Task 1 — `LICENSE`                           |
| PKG-02 | `package.json` `repository` field (placeholder URL)               | Task 2 — package.json                        |
| PKG-03 | Pre-build clean of `out/src/` and `out/test/`                     | Task 2 — `clean-out.mjs` + package.json hook |
| PKG-04 | `.vsix` excludes `*.map` files                                     | Task 3 — .vscodeignore + build clean         |
| STR-02 | `.vscodeignore` lists only tool dirs that actually exist           | Task 3 — .vscodeignore pruning               |

## must_haves (goal-backward verification)

For Phase 11 to be considered successful, the following must be TRUE:

1. `test -f LICENSE` exits 0 **and** file starts with `MIT License` line + contains `Copyright (c)`.
2. `grep -E '"repository":' package.json` matches **and** the value is `{ "type": "git", "url": "https://github.com/YOUR_USERNAME/vscode-ue-helper.git" }`.
3. `scripts/clean-out.mjs` exists at repo root scripts/ **and** running it removes both `out/src/` and `out/test/` when they exist and is a no-op when they don't (idempotent).
4. `package.json` contains both `prepackage` and `prebuild` hooks — `prepackage` runs build, `prebuild` runs clean-out (verified by: build → clean → esbuild runs in that order).
5. `*.map` line exists in `.vscodeignore` (verified by `grep '\*\.map' .vscodeignore`).
6. `.vscodeignore` no longer contains `.omo`, `.codewiki`, or `.hermes` lines (verified by `grep -cE '\.(omo|codewiki|\.hermes)' .vscodeignore` == 0).
7. `.vscodeignore` still contains `.claude/**` (existing dir rule preserved).
8. `npm run package` produces 0 vsce WARNING lines (verified by running the package command and grepping for `WARNING`).
9. The resulting `.vsix` archive contains no `*.map` entries (verified by `unzip -l *.vsix | grep -c '\.map'` == 0).
