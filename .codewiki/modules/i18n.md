# i18n 模块文档

## 基本信息
- **路径**: `src/i18n/`
- **文件数**: 1 (+ locales/)
- **语言**: TypeScript + JSON (locale files)
- **职责**: 国际化（中英双语）。必须最先初始化——Logger 的输出也要翻译。

## 符号表

### 导出函数

| 函数名 | 文件:行号 | 签名 | 说明 |
|--------|----------|------|------|
| initI18n | `src/i18n/index.ts` | `initI18n(): void` | 根据 `vscode.env.language` 自动选 zh/en locale |
| t | `src/i18n/index.ts` | `t(key: string, params?: Record<string, string>): string` | 翻译函数，支持 `{name}` 占位符替换 |

### Locale 文件

| 文件 | 说明 | 条目数 |
|------|------|--------|
| `src/i18n/locales/zh.json` | 中文翻译 | 70+ keys |
| `src/i18n/locales/en.json` | 英文翻译 | 70+ keys |

## 内部依赖图

```
initI18n ──→ vscode.env.language
t ──→ locale JSON 文件 (zh.json / en.json)
```

## 对外依赖

| 依赖模块 | 导入的符号 | 用途 |
|----------|-----------|------|
| vscode | env.language | 检测 VS Code 语言设置 |

## 被依赖情况

- `extension.ts` — 第一个调用（`src/extension.ts:59` `initI18n()`）
- `core/logger.ts` — Logger 信息可能被翻译
- 所有 UI 模块 — 通过 `t()` 函数输出中/英文界面

## 关键设计

1. **最先初始化**：`extension.ts:15` 注释明确 "必须在 Logger 之前"
2. **占位符替换**：`t('showInfo.workspace', { path: '/e/foo' })` → `"工作区: /e/foo"` (zh) / `"Workspace: /e/foo"` (en)
3. **缺失 key 处理**：返回 key 本身作为 fallback，防止空白 UI
